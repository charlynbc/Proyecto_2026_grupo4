
# Comparación de tecnologías Backend

Para la POC se prepararon tres alternativas dentro del ecosistema Java:

- Spring Boot
- Quarkus
- Jakarta EE con GlassFish

La idea es realizar pruebas similares sobre las tres tecnologías para poder
compararlas en condiciones parecidas.

## Prueba inicial

Cada tecnología debe ser capaz de publicar un endpoint REST simple.

### Spring Boot

GET /hola

Puerto:

8080

### Quarkus

GET /hola

Puerto:

8081

### Jakarta EE / GlassFish

GET /poc-jakarta/api/hola

Puerto:

8082
